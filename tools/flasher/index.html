AgentMeter Flasher

Plug in the ESP32 over USB, connect, pick your firmware .bin files, flash. Chrome or Edge only (Web Serial). Runs locally; nothing is uploaded.

Web Serial is not available. Open this page in Chrome or Edge on http://localhost:5174.

1. Connect

Not connected. If connect fails, hold the BOOT button while clicking Connect, and check the USB cable carries data.

2. Firmware

PlatformIO files: firmware/esp32/.pio/build/<env>/{bootloader,partitions,firmware}.bin; boot_app0.bin is in ~/.platformio/packages/framework-arduinoespressif32/tools/partitions/. Offsets depend on the chip: pick it here, and it is corrected from the detected chip after you connect. S3: use the USB-C port marked UART/COM for flashing; on the native "USB" port, hold BOOT, tap RST, release BOOT if connect fails, and re-pick the port after each reset.
